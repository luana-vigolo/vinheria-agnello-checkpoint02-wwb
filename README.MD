#  Vinheria Agnello | Checkpoint 02

## Sobre o Projeto

O projeto Vinheria Agnello foi desenvolvido como parte do Checkpoint 02, com o objetivo de aprimorar os conhecimentos em desenvolvimento web utilizando HTML, CSS e JavaScript.

Nesta etapa, o projeto dá continuidade à proposta de cadastro de vinhos, implementando funcionalidades para gerenciar informações de estoque e analisar a safra dos produtos cadastrados.

## Funcionalidades Implementadas

- Cadastro de vinhos: permite cadastrar vários vinhos em sequência.
- Validação de dados: verifica as informações inseridas pelo usuário.
- Controle de estoque:identifica vinhos com estoque baixo, inferior a 5 unidades.
- Classificação dos vinhos: classifica os vinhos como jovens, amadurecidos ou antigos.
- Exibição de informações: apresenta os dados dos vinhos utilizando alertas e o console.
- Resumo dos cadastros: informa a quantidade total de cadastros realizados, os vinhos com estoque baixo e o vinho com a safra mais antiga.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

## Conceitos Aplicados

- Criação e reutilização de funções.
- Validação de entradas.
- Escopo de variáveis.
- Estruturas de repetição e iteração.
- Manipulação de informações sem utilizar arrays ou objetos, conforme os requisitos da atividade.
