Sobre o Projeto

Este é um sistema básico para cadastro e análise de vinhos artesanais da Vinharia Agnello. Através dele, é possível cadastrar novos vinhos, informando: nome, tipo, safra e quantidade em estoque, para consulta e organização da vinícola.

Abra o console do navegador para acompanhar o cadastro do vinho.
